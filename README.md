Simulador do Semáforo

Descrição do projeto

Este projeto consiste em um simulador de semáforo desenvolvido para a disciplina de Arquitetura e Organização de Computadores. O objetivo é demonstrar o funcionamento de uma máquina de estados utilizando os modelos de Moore e Mealy.

Tecnologias utilizadas

- HTML
- CSS
- JavaScript

Funcionamento

O simulador apresenta três estados: verde, amarelo e vermelho. É possível controlar a mudança das luzes manualmente ou ativar o modo automático.

O projeto também apresenta:

- Máquina de estados de Moore;
- Máquina de estados de Mealy;
- Dois flip-flops D;
- Equações do circuito;
- Histórico das mudanças de estado.

Como executar

1. Acesse o repositório no GitHub.
2. Baixe o arquivo HTML.
3. Abra o arquivo em um navegador, como Google Chrome.
4. Utilize os botões para controlar o simulador.
